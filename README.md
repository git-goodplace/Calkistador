# Калькулятор финансов

Личные деньги и деньги бизнеса в одном приложении — для самозанятых и ИП-одиночек.

## Зачем

Рынок разделён: трекеры расходов для людей (Дзен-мани, CoinKeeper, Monefy) и управленческий
учёт для компаний (Финтабло, ПланФакт, Финолог). Ни один массовый продукт не ведёт оба
контура как равноправные — в конкурентном анализе эта фича набрала 21% покрытия, минимум
из 27 проверенных.

Предприниматель-одиночка сегодня живёт либо в Excel, либо в связке «личный трекер + Мой
налог», где данные не связаны и реальный доход после налогов не виден. Это и есть
конкурент, с которым мы сравниваемся.

**Целевой пользователь:** самозанятый или ИП-одиночка, у которого налоги закрыты «Моим
налогом» или бухгалтером, а учёт денег — нет.

**Условие победы:** регулярность ввода, а не глубина отчётов. На десктопе Excel и так
удобен; проигрывает он в телефоне.

## Что уже сделано

- `src/domain/money.ts` — деньги целыми копейками, без плавающей точки.
- `src/domain/tax/` — расчёт налоговой нагрузки бизнес-контура: НПД, УСН «Доходы»,
  УСН «Доходы минус расходы», ОСН-ИП (НДФЛ). Логика заложена и для выключенных режимов
  (ПСН, АУСН, ЕСХН). Подробно — в [docs/tax-regimes.md](docs/tax-regimes.md).
- `src/domain/model/` — модель данных: счета и вычисляемые остатки, категории с
  разделением по контурам, операции четырёх типов с валидацией, слияние изменений для
  офлайн-синхронизации.
- `src/storage/` — локальная база на IndexedDB (Dexie) за интерфейсом репозитория плюс
  реализация в памяти для тестов.
- `src/state/` — `LedgerService`: единственная точка записи, каждая операция проходит
  валидацию домена. Не зависит от React — пригодится Telegram-боту третьего этапа.
- `src/ui/` — интерфейс: главный экран с остатками по контурам, экран быстрого ввода с
  клавиатурой, счета и категории.

**Первый этап закрыт.** Приложение открывается в браузере, ведёт учёт и работает офлайн.

```bash
npm install
npm run dev      # localhost:5173
npm run build    # сборка PWA в dist/
npm test         # тесты домена и сервиса
npm run typecheck
```

## Тесты

Тесты запускаются без установки зависимостей: Node 22+ исполняет TypeScript напрямую,
срезая типы.

```bash
npm test
```

## Публикация

Приложение выкладывается на GitHub Pages автоматически: каждое изменение в `main`
запускает тесты, проверку типов и сборку, и только при зелёных проверках публикуется.
Настройка — в `.github/workflows/deploy.yml`.

Адрес: https://git-goodplace.github.io/Calkistador/

Разовый архив для загрузки на любой другой хостинг (`npm run build`, затем содержимое
`dist`) тоже годится — все пути в сборке относительные, поэтому она работает и в корне
домена, и в подпапке. Для офлайн-режима и установки на домашний экран обязателен HTTPS.
